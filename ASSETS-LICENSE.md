## Cómo usar

- **Una fila por asset.** Los assets propios también se registran (respaldan autoría).
- **Columna "Atribución (texto a publicar)":** copiar tal cual a los créditos del juego (M131).
- Si una licencia cambia o se revoca, editar la fila con fecha y motivo (**nunca borrar historial**).
- Los assets rechazados se conservan con motivo para trazabilidad.

## Formato

| Campo | Descripción |
|-------|-------------|
| ID | Identificador único del asset |
| Asset | Nombre descriptivo |
| Tipo | Tipo de asset (código, fuente, plugin, arte_3d, audio, etc.) |
| Origen | Propio / Tercero / Dominio público |
| Autor | Nombre del autor (real o seudónimo) |
| Fuente | URL de donde se obtuvo |
| Licencia | Licencia aplicable |
| Uso comercial | Sí / No |
| Atribución exigida | Sí / No |
| Atribución (texto a publicar) | Texto exacto para créditos |
| Estado | Activo / En evaluación / Retirado / Rechazado |
| Fecha de ingreso | Fecha de incorporación al proyecto |
