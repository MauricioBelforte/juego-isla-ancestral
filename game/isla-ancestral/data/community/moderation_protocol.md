# Protocolo de Moderación — Isla Ancestral

## Flujo de reporte
1. Usuario reporta → categoría + descripción
2. Mod revisa (SLA 48h)
3. Acción: advertir / silenciar / ban / borrar
4. Notificar al reportante
5. Log en #mod-log

## Jerarquía de acciones
| Nivel | Acción | Duración |
|---|---|---|
| 1 | Advertencia privada | — |
| 2 | Silencio | 24-48h |
| 3 | Ban temporal | 7 días |
| 4 | Ban permanente | — |

## Reglas
- 2 mods de acuerdo para ban permanente.
- Todas las acciones logueadas.
- Apelación vía email.
