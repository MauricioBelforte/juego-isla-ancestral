1. **Sonda de licencia invalida si se muta TODAS las ocurrencias**: el reemplazo global
   "OFL"->"BSD" tambien muta `licencias_permitidas` -> BSD queda autorizado y FontAuditor
   reporta 0 errores (falso verde). Mutar SOLO la entrada de `fuentes[]`.
2. `save_manager.gd` roto en HEAD (error de compilacion ajeno): no bloquea las suites M88
   pero distorsiona el exit code de `test_fonts_m88.gd` (-1 en vez de 1). Interferencia ajena.
3. `git checkout` fallo con "unable to unlink" (lock Windows tras correr Godot) ->
   restaurar via `git show HEAD:<ruta>` + write binario.
