# Log 817: Anillo de arena VISIBLE — fix commit() + vertex_color + exageración playa

**Fecha:** 2026-09-11
**Hora:** 02:48
**Modelo:** glm-5.3-flash
**Plataforma:** Kilo Code

## Resumen
El usuario llevaba varias sesiones sin poder ver el anillo de arena (franja entre el disco verde y el mar). Se encontraron TRES causas combinadas y se corrigieron todas. Verificado con capturas in-game (orden verde → arena blanca → mar confirmado visualmente, FPS 60).

## Causas encontradas (en orden de descubrimiento)

1. **Exageración ×4 del impostor sepultaba el anillo:** MONT_EXAG se aplicaba a TODAS las celdas h≥4 → la playa (h 4-5) se dibujaba como prismas de 14-17 m por encima del anillo a y=4.3, y `_color_por_altura(top exagerado)` nunca elegía COLOR_ARENA (la playa se veía verde pasto). **Fix:** exageración solo para h>6 (montañas idénticas); playa a altura real (~3.4-5.1 m) y color arena.

2. **Triángulos después de `st.commit()` (causa raíz histórica):** el bucle del anillo estaba DESPUÉS de `mi.mesh = st.commit()` → los vértices se agregaban a un mesh ya cerrado y se descartaban en silencio. El anillo NUNCA entró al mesh (por eso el fix de winding del Log 805 no produjo cambios visibles). **Fix:** construir anillo ANTES del commit, mismo mesh del disco.

3. **Material sin `vertex_color_use_as_albedo`:** el material DiscoBase usaba `albedo_color=verde` sin colores por vértice → aun dentro del mesh, el anillo se pintaba verde. **Fix:** `albedo_color = Color.WHITE` + `vertex_color_use_as_albedo = true` (disco verde y anillo arena vía vértices, sin oscurecer el disco).
