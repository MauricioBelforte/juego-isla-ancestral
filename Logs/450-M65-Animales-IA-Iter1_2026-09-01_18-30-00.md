## Decisiones clave

1. **Plan-actual de M65 estaba en C#/Unity** (`FaunaManager.cs`, `MonoBehaviour`, `ScriptableObject`). No aplica a este proyecto Godot. Iter 1 traduce la **intención** a GDScript consumiendo la API que M36 ya emite (`solicitar_movimiento`). El plan-actual queda como referencia historica.

2. **No reutiliza `NPCAgent` (M64)** porque tiene errores pre-existentes en `state_machine.gd` que otros agentes están arreglando. La capa M65 es **independiente** y solo consume las señales de M36. Si M64 se repara, ambos pueden coexistir (M65 para fauna, M64 para NPC).

3. **Movimiento 3D via `global_position`** (no `NavigationServer3D`): iter 1 cubre el contrato. La función `_procesar_individuo` es el hook donde se puede cambiar la implementación sin tocar la API. Producción debería usar `NavigationServer3D` para evitar atravesar voxels/obstáculos (M08).

4. **Auto-registro via `_ready` de fauna_behavior** (duck-typing): si M65 no está, fauna_behavior funciona igual. Cero acoplamiento duro. Lo mismo aplica al `_exit_tree`.

5. **Presupuesto global 40** (M61): tope de animales simultáneos en el mundo. Configurable via `set_presupuesto_max(n)`. Si está lleno, los nuevos registros se ignoran con `push_warning` (no rompe el juego).

## Pitfalls documentados (memoria colectiva)

- **step cap con `minf(vel*dt, dist)`**: sin cap, si `vel*dt > dist`, el nodo se "pasa" del destino y queda en_movimiento=true para siempre. La forma correcta es `step = minf(vel*dt, dist)` y luego `if dist - step < 0.05: en_movimiento = false`.

- **El `min` con Float vs Dictionary values**: en Godot 4, `min(vel*dt, dist)` falla si uno es `Variant`. Usar `minf()` cuando ambos son float explícitos.

- **Plan escrito en C#/Unity en este proyecto Godot**: otros agentes (Deepseek V4 Flash principalmente) escribieron planes Unity para modulos que en realidad son Godot 4. La traduccion al contexto real del proyecto es responsabilidad del implementador.

- **Duck-typing en `_ready`**: si el nodo M36 no tiene autoload M65, el auto-registro falla silenciosamente (con `if ai != null`). El fauna_behavior sigue funcionando sin M65. La integración es opcional, no obligatoria.
