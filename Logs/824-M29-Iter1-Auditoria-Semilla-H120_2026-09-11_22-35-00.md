## Cambios Realizados

**Código (brecha real H120 — `game_clock.gd`):**
1. `_semilla_partida` generada una vez por partida con `randi()` del motor (C56-safe: la primera versión usaba `Time.get_unix_time_from_system()` y el escáner anti-reloj-SO de M30 la marcó — corregida a la fuente de entropía idiomática de Godot).
2. `get_semilla_partida()` / `set_semilla_partida(int)` — para M59 (crear/restaurar partida) y tests.
3. `valor_diario(ns_consumidor, minimo, maximo)` — entero determinista del día actual por namespace (misma partida + mismo día + mismo namespace = mismo valor).
4. `rng_diario(ns_consumidor)` — RandomNumberGenerator reproducible del día (secuencias estables entre cargas del mismo save).
5. Hash FNV-1a 32 bits sobre `semilla_partida + dia_absoluto + ns_consumidor` — determinista entre sesiones y versiones del motor (hash() de Godot no lo garantiza).
6. Persistencia: `"semilla_partida"` en el save sección "time" — misma secuencia al recargar; `restore_save_data` restaura o genera.
7. Flag `usar_semilla_tiempo` del config consumida por fin: true = semilla por partida (default), false = 0 = determinista global (tests/QA).
