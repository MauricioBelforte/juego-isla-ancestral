## Cambios Realizados

1. **`tests/test_m65.gd` — preloads muertos corregidos:** `res://scripts/fauna/pack_logic.gd` /
   `school_logic.gd` (rutas viejas tras el move del Log 584) → `res://scripts/animales_ia/...`.
   La suite volvio a ser ejecutable (antes: 6x SCRIPT ERROR, EXIT 1).
2. **`scripts/animales_ia/m65_animal_ai.gd` — integracion PackLogic/SchoolLogic (el fix de BUG-080b):**
   - `registrar(nodo)` → `_grupo_agregar(nodo, instancia_id)`: clasifica la especie por datos del
     catalogo M36 (`gregaria` + `clase`): **gregaria + TERRESTRE → PackLogic** (manada) y
     **gregaria + (ACUATICA|AEREA|ANFIBIA) → SchoolLogic** (banco); guarda `radio_alarma`/
     `velocidad_huida` por especie.
   - `tick(dt)` → `_grupos_tick(dt, _pos_jugador_actual())`: cohesión/aliénamiento/separación/
     migración emiten `solicitar_movimiento` (ya conectado en `registrar`); la **huida coordinada**
     (`_huir_coordinado_pack` / `_huir_coordinado_school`) sobreescribe el destino de TODO el grupo
     cuando un miembro esta dentro del radio de alarma.
   - `desregistrar(nodo)` → `_grupo_remover(...)`.
   - Nuevo metodo QA read-only: `grupo_tamanio(especie_id)` (tamano del pack/school, 0 si no existe).
3. **Fixes de semantica/spec en `pack_logic.gd` y `school_logic.gd`:**
   - `.global_position` (property) → `get_global_position()` (metodo, duck-typed): funciona con el
     mock de test (RefCounted que expone el metodo) Y con Node3D real; el mismat era la causa de
     3 fallos del pack/school suite.
   - `PackLogic.limpiar()` ahora vacia el grupo completo (espejo de `SchoolLogic.limpiar`; era el
     spec del test L64-65 "pack limpio tamanio 0").
   - `PackLogic.tick` elige lider con >=1 miembro y cohesión solo con >=2 (spec "nuevo lider tras
     timeout" con 1 miembro restante).
   - Se quito la llamada `pack.limpiar()` de cada tick del autoload (con la nueva semantica de
     full-clear habia borrado la manada entera en runtime; el cleanup lo cubre `desregistrar`).
4. **Fixes de la integracion misma (bugs detectados al probar):**
   - `push_info` → `print` (parse error en la version del binario).
   - `_pos_jugador_actual`: `root.get_first_node_in_group("player")` era invalido (el root de
     SceneTree es un `Window`, sin ese metodo) → `SceneTree.get_nodes_in_group("player")`.
   - `Resource.get("k", default)` (2 args) → acceso directo a propiedades (`especie.clase`,
     `especie.gregaria`, `especie.radio_alarma`, `especie.velocidad_huida`): el 2-arg lanzaba
     SCRIPT ERROR "Expected 1 argument(s)" en runtime.
5. **Prueba nueva del flujo real de produccion en `tests/test_m65.gd`:**
   `fauna_behavior._ready → animal_ai.registrar → PackLogic` — se instancia un nodo con el script
   `fauna_behavior` + especie `conejo_pradera` (gregaria), se agrega al arbol y se verifica
   `animal_ai.grupo_tamanio("conejo_pradera") >= 1`.
6. **Documentacion:** M65 `04-Codigo` (rutas obsoletas `fauna/` → `animales_ia/`, bloque P-38,
   firma), `05-Checklist` (3 `[?]`→`[x]` L109/L115/L120 + Totales 89/1/0 + Notas P-38),
