## Cambios Realizados (todos del lado del TEST — código de producción M14 intacto)

1. **`is_equal_to` → `is_equal`** (58 renombres en los 3 tests M14): el gdUnit4 del repo
   expone `is_equal(expected)`; `is_equal_to` no existe en el addon (0 ocurrencias) →
   `SCRIPT ERROR: Nonexistent function 'is_equal_to'` en cada assert.
2. **`free()` sobre RefCounted** (`test_contenedor_inventario.gd`): `ContenedorInventario`
   / `InventorySlot` son `extends RefCounted`; `.free()` → `SCRIPT ERROR: Attempted to free
   a RefCounted object` → `_contenedor = null` / el local `nuevo` pasa por GC. (Los `.free()`
   de `test_inventory_economy.gd` son correctos: `InventarioService`/`EconomyManager`
   son Node.)
3. **Contadores de señal** (`test_slot_changed_on_add/remove`, `test_signals_emitted`):
   las lambdas GDScript **capturan locales por valor** → el contador no mutaba (leía 0).
   Fix: holder por referencia (`var holder := [0]`, `var c := {"saldo":0,...}`).
4. **Fixtures con ids inexistentes** (`test_deserializar`, `test_save_restore_roundtrip`):
   `madera`/`piedra` no están en el catálogo M15; `deserializar()`/`restore_save_data()`
   validan contra el `ItemDatabase` **vivo** (arranca en el runner) y filtraban los ids →
   conteo 0. Fix: `wood`/`stone` (ids reales M15).
5. **`test_puede_apilar_false_different_item` → `test_puede_apilar_false_empty_slot`**:
   la API real es `puede_apilar(cantidad_extra, stack_max)` (no recibe item id; la
   identidad la garantiza el llamador `add_item` pasada 1). El caso "false" que la API
   expresa es slot vacío. Test rediseñado al contrato real.
