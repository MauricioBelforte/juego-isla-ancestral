### Cambio a `generar_variante.py`: flag `--ratio`

Para no bajar el `DECIMATE_RATIO = 0.7` global (que está calibrado para el
resto, E-23), agregué un flag `--ratio N` a `generar_variante.py`:

```python
def generar(modulo, blend_alta, modo, ratio=None):
    dec_ratio = DECIMATE_RATIO if ratio is None else ratio
    ...
    .replace('@@DEC_RATIO@@', repr(dec_ratio))
```

Uso:
```bash
python generar_variante.py 15-Recursos nido_cocos_lowpoly --baja --ratio 0.4
```

**Lección:** el ratio 0.7 default destruye mallas planas (E-23). Para casos
puntuales con mucha geometría densa (vegetación frondosa, nidos, racimos),
bajar el ratio a 0.4-0.5 mantiene la silueta sin destruirla. El `--ratio` es
un escape valve; no cambiar el default.
