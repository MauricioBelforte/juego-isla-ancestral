# Log 265: M53 UI-UX (iter. 1) — Capas modales + framework + navegación gamepad

**Fecha:** 2026-08-30
**Modelo:** Deepseek V4 Flash
**Plataforma:** Kilo

## Resumen
Iteración 1 del M53 (UI-UX) sobre la infraestructura liberada por MiMo V2.5. Se implementaron las
capas modales formales (DialogLayer, PauseLayer, MenusLayer, ConfirmPopup), se conectó el framework
de pila de UIManager (registro automático de UILayer, open/close de capas, navegación por acciones
M57) y se integró la localización M87 en los textos de UI. Verificado: el juego monta las 4 capas
via UIRoot y las registra en UIManager.

## Cambios Realizados

### Código (Godot)
- `scripts/ui/layers/dialog_layer.gd` — **NUEVO** DialogLayer (class_name, extiende UILayer):
  presentación formal del diálogo M21. Escucha DialogueManager (node_entered/dialogue_ended/
  option_selected), ventana con speaker/texto/opciones, fondo dim, avanzar con Enter/E,
  elegir con 1-4, claves localizadas M87.
- `scripts/ui/layers/pause_layer.gd` — **NUEVO** PauseLayer: menú de pausa (Continuar/Ajustes/
  Guardar/Salir) con señales, navegable, localizado.
- `scripts/ui/layers/menus_layer.gd` — **NUEVO** MenusLayer: menú principal (Jugar/Continuar/
  Ajustes/Créditos/Salir), consumido por M89.
- `scripts/ui/layers/confirm_popup.gd` — **NUEVO** ConfirmPopup: popup genérico OK/Cancelar
  (para UIManager.open_confirm y M57 confirm).
- `scripts/ui/ui_root.gd` — **NUEVO** UIRoot: punto de montaje de las capas (CanvasLayer 100).
- `scripts/ui/core/ui_manager.gd` — Modificado:
  - `register_layer`/`unregister_layer` para el registro automático desde UILayer.
  - `_unhandled_input`: navegación direccional con acciones M57 (mover_*), abrir/cerrar capas
    con `pausa`, usando MenuNavigator.
  - `_apply_process_mode`: MODAL_SIMPLE/FULL usan `PROCESS_MODE_WHEN_PAUSED` (bug corregido:
    antes DISABLED congelaba la propia capa e impedía navegar).
  - `open_confirm`/`_on_dialog_requested`: buscan capas de forma robusta via `_buscar_capa`.
- `scripts/ui/core/ui_layer.gd` — Modificado: registro automático real (sin ternario suelto),
  `PROCESS_MODE_WHEN_PAUSED` para modales.
- `scripts/main_island.gd` — Modificado: `_crear_ui_root()` monta el UIRoot.
- `locales/es.po` / `en.po` — añadidas claves SETTINGS.PAUSA, CONTINUAR, AJUSTES, GUARDAR,
  SALIR, JUGAR, CREDITOS, CONFIRMAR, CANCELAR, TITULO, ELEGIR_OPCION, ADVANCED.
- `scripts/ui/test_ui_framework.gd` — **NUEVO** test del framework (pila, registro automático,
  layer_type, open/close). 0 fallos.
