## Resumen

Se convirtio el job `Mojibake scan (informativo)` de `quality.yml` en un **gate
bloqueante** (`Mojibake scan (gate)`), cerrando P-20. El detector
`scripts/diagnosticar_mojibake.py` paso de 164 a 301 lineas: se le extrajeron los
helpers `es_excluido()` y `clasificar()` (probables) y se le agrego un
`--selftest` de **21 casos en las DOS direcciones** (16 deben pasar limpios /
4 deben caer en SUCIO / 1 en IRREVERSIBLE / 5 en EXCLUIDO / 2 documentados).

Se siguio el orden estricto pedido: **(1) medir en frio, (2) fijar las
exclusiones, (3) recien ahi cablear**. Nada se activo por herencia: cada
exclusion tiene una medicion detras.

## El diagnostico: por que el scan NO bloqueaba

El job viejo tenia **tres falsificadores apilados**, no uno:

| # | Falsificador | Efecto |
|---|---|---|
| 1 | `continue-on-error: true` | el job se pone verde aunque el step falle |
| 2 | sufijo `\|\| true` al final del `run:` | fuerza exit 0 del step |
| 3 | `\| tail -25` | **ademas se come el exit code**: `$?` pasa a ser el de `tail` (siempre 0) — trampa 75 |

El #3 es el mas sutil: aunque se hubieran quitado 1 y 2, el pipe ya habia
convertido el resultado del detector en irrelevante. Quitar solo `\|\| true`
habria dejado un gate que igual no bloquea.

### Paso 3 — Cablear el job

`.github/workflows/quality.yml` (diff **25/7**), job `encoding-guard`:

```yaml
      - name: Mojibake detector — selftest (probarlo en rojo)
        run: python3 scripts/diagnosticar_mojibake.py --selftest

      - name: Mojibake scan (gate)
        run: |
          python3 scripts/diagnosticar_mojibake.py > /tmp/mojibake.txt 2>&1
          codigo=$?
          tail -25 /tmp/mojibake.txt
          if [ "$codigo" -ne 0 ]; then
            echo "::error::Mojibake en contenido versionado. Reparar con: python scripts/fix_encoding.py"
          fi
          exit $codigo
```

- `continue-on-error: true` **eliminado**.
- Sufijo OR-true **eliminado**.
- El `tail` se conserva para el log **pero ya no toca el exit code**: se captura
  `$?` en `codigo` **antes** del pipe y se hace `exit $codigo` al final.
- El selftest va como step **anterior**: si alguien rompe el detector, el CI lo
  dice antes de que el detector juzgue al repo.
- `encoding-guard` ya estaba en `summary.needs` (no hubo que agregarlo).

## Verificacion — probado en las DOS direcciones

**El detector:**
- `--selftest` → **21/21, exit 0**.
- **Probado en rojo, 2 sondas independientes** (un selftest que solo prueba el
  verde no es selftest):
  1. Patron aflojado a `A-tilde` desnuda (el error M-06 exacto) → cae el caso
     `A-tilde SUELTA` (`esperaba limpio, obtuvo SUCIO`), **exit 1**.
  2. Quitada la exclusion `.kilo` → cae su caso (`esperaba EXCLUIDO, obtuvo
     SUCIO`), **exit 1**.
  El original quedo **verde (exit 0)** despues de cada sonda.
- `--basura` → **exit 2** (uso), distinto de 1 (hallazgo): un CI no debe
  confundir "no pude correr" con "encontre mojibake".
- No se autodetecta: `clasificar()` sobre el propio script devuelve `None`.
- Corrida real: working tree `0/0/239` → **exit 0**; HEAD `0/0/93` → **exit 0**.

**El step REAL del CI** (no una copia: se extrae el `run:` del YAML y se ejecuta
con un shim de `python3`):

```
### 1) repo LIMPIO            -> EXIT=0  (esperado 0)
### 2) INYECCION mojibake real -> EXIT=1  (esperado 1)
       SUCIO 1  ->  ./game/isla-ancestral/scripts/_p20_sonda_mojibake.gd
       ::error::Mojibake en contenido versionado. Reparar con: python scripts/fix_encoding.py
### 3) sonda borrada           -> EXIT=0  (git status: 0 lineas)
```

⚠️ **Correccion de mi propio test (v1 no tenia dientes):** la primera version
escribia `\xc3\xb3` creyendo que era mojibake. **No lo es:** `C3 B3` decodifica
como `o` con acento **perfecta** — el test habria aprobado un gate roto (falso
negativo). El mojibake es la *codificacion UTF-8 del texto corrupto*:
`A-tilde + superindice-3` = bytes **`C3 83 C2 B3`**. La v2 inyecta eso y falla
como debe. *Un test que no se puede poner en rojo no prueba nada.*

## Limitaciones (medidas, NO resueltas — se reportan, no se tapan)

1. **El gate solo bloquea con `SUCIO`.** `IRREVERSIBLE` (U+FFFD: los bytes
   originales ya no existen, ninguna herramienta los recupera) y `EXCLUIDO` se
   informan y no bloquean. Es deliberado: un IRREVERSIBLE necesita reescritura a
   mano, no puede frenar el CI de todos.
2. **9 archivos versionados con NUL quedan fuera del gate.** El detector los
   saltea (`b'\x00' in raw` → `None`). Incluye **`CHECKLIST-GLOBAL.md`** y
   `DOCUMENTACION/16-Crafting/plan-actual/04-Codigo.md`, mas 7 `Logs/_*.txt`.
   Es una limitacion **pre-existente**, no introducida hoy: el gate no puede ver
   mojibake en esos 9 archivos. Dueño: quien corresponda segun su fila.
3. **`AGENTS.md` es punto ciego por ruta.** Si alguien corrompe `AGENTS.md` de
   verdad, el gate no lo vera. Es el precio de que el archivo documente el
   sintoma con ejemplos literales.
4. **`Logs/` esta excluido** → mojibake en logs no se detecta (exclusion pedida
   explicitamente; los logs son prosa historica).
