10. ❌ **[?] Test headless FALLA / bug crítico de lógica.** `EventDefinition.coincide_fecha`
    (event_definition.gd:77-81):

    ```gdscript
    func coincide_fecha(dia: int, mes: int, estacion: int) -> bool:
        var coin_dia := dia == 0 or dia == dia   # <-- param == param SIEMPRE true
        var coin_mes := mes == -1 or mes == mes   # <-- siempre true
        var coin_est := estacion == -1 or estacion == estacion  # <-- siempre true
        return coin_dia and coin_mes and coin_est
    ```

    El parámetro `dia` oculta al miembro `dia`, así que `dia == dia` es una auto-comparación que
    siempre es verdadera. Resultado: `coincide_fecha` **devuelve SIEMPRE true** →
    - `_verificar_inicio_evento` inicia TODOS los eventos cuyo franja coincida, cada día.
    - `_verificar_aviso_previo` emite aviso para todos los eventos cada día.
    El test `test_eventos.gd:46` `_check("no coincide mes errado", not ev.coincide_fecha(15, 2, 0))`
    **falla** (espera false, recibe true). Por tanto el claim "test headless 0 fallos" es falso.

**Hallazgo menor (no bloqueante):** `Ocupar_npcs_para_evento` (event_manager.gd:529) emite
`bus.time.evento_activado` accediendo al sub-emitter `EventBus.time` directamente; funciona si
EventBus expone `.time`, pero es frágil (mejor usar la señal tipada del bus).

## Acción recomendada (para agnes-2.5-flash o siguiente iteración)

### M64
- Usar la API real de M19 en lugar de los métodos inexistentes:
  - Perfil: `var v = vm.obtener_vecino(name); if v != null: perfil = v.obtener_perfil()`
    (villager.gd ya tiene `obtener_perfil() -> Resource`).
  - Spawn de hogar: exponer `VillagerManager.get_spawn_for_parcela(idx)` o usar
    `TerrainLocator`/`colocar_sobre_terreno` con el hogar conocido.
  - Hogares: exponer `VillagerManager.get_hogares() -> Dictionary` (wrapper de `_hogares`) o
    usar `hogar_de(id)` + posición de parcela ya existente.
- Extender `test_ia_npc.gd` para que instancie un VillagerManager real (o doble que exponga las 3
  APIs) y ejercite `_get_profile`, `get_location_position("casa")` y el respawn.

### M74
- Corregir `coincide_fecha` comparando contra los miembros: `self.dia == dia`, `self.mes == mes`,
  `self.estacion == estacion`.
- Re-ejecutar `test_eventos.gd` tras el fix (debe pasar la aserción de no-coincidencia).
