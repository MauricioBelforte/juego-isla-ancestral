## Hallazgo 1 - BUG-101: bug REAL de producto en `item_database.gd` (M159)

`test_item_data.gd` bloque P/Q fallaba con `items.size() .is_greater_than(0)` = false.

**Sonda headless (medida, no inferida):**
- `_items.size()` = 111; `_by_category.size()` = 16 (incluye clave 5 = COCINA).
- Acceso directo `_by_category[5].size()` = **10** (el diccionario TIENE los datos).
- `get_items_by_category(ItemData.Categoria.COCINA).size()` = **0**.
- `get_items_by_rarity(ItemData.Rareza.COMUN).size()` = **0** (clave 0 = 78 items).

**Causa raiz:** `_registrar_item()` guardaba arrays SIN TIPAR (`[]`), pero los getters
declaran `-> Array[ItemData]`. En Godot 4.7 la conversion implicita falla en runtime:
`SCRIPT ERROR: Trying to assign an array of type "Array" to a variable of type "Array[ItemData]".`
El error aborta el `return` -> la funcion devuelve el `Array[ItemData]` VACIO por defecto.

**Alcance:** el archivo tiene UN solo commit (`4234bca`, "primera version funcional") ->
la API **nunca funciono**. **0 consumidores en produccion** (unico llamador: el test).
Bug real pero dormido.

**Fix:** indices tipados `Array[ItemData]` + getters que construyen un `Array[ItemData]`
seguro (vacio si la clave no existe). Post-fix medido: COCINA = 10, COMUN = 78, 0 SCRIPT ERROR.

Registrado en `DOCUMENTACION/11-BUGS.md` como **BUG-101** (fila + seccion).

## Hallazgo 2 - `test_stable_flows.gd`: 3 defectos de TEST (no de producto)

1. **Metodo inexistente:** bloque J llamaba `_calendar.pausar()`; la API real es `pausa()`
   (y `resume()`). El bloque abortaba -> 0 checks. Fix: `pausa()`.
2. **`_config` null:** `before_test()` creaba `_calendar = TIME_SCRIPT.new()` SIN `_ready()`
   -> `_config` null -> `get_save_data()`/`restore_save_data()` lanzaban
   `Invalid access to property 'usar_formato_12h' on a base object of type 'Nil'`.
   Fix: los nodos de prueba ahora entran al arbol (`root.add_child(...)`), lo que dispara
   `_ready()` Y hace resolubles los `get_node_or_null("/root/<Autoload>")`.
3. **Ids inexistentes:** la suite usaba `"madera"`/`"piedra"`/`"comida"`, que NO existen en
   el catalogo (M15). `inventario_contenedor.gd:133` (`deserializar`) valida el id contra
   `ItemDatabase` y **descarta** los desconocidos -> el roundtrip daba 0.
   Fix: ids validos `wood`/`stone`/`clay` (los 3 `apilable=true, stack_max=99` -> mismo
   comportamiento de apilado que el fallback 99: cambio behavior-preserving).

**Bonus de honestidad:** el bloque J no tenia NINGUNA asercion (0 checks). Se le agregaron 3
aserciones reales sobre la delegacion `pausa()/resume()` al GameClock. El bloque K tambien era
debil (solo `!= null`); ahora verifica un roundtrip real de `eventos_visitados`.

**Efecto colateral medido:** el ruido `ERROR: Can't use get_node() with absolute paths from
outside the active scene tree` bajo de ~20+ lineas a **0**.
