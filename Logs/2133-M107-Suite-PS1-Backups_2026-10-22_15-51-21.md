### 2.2 Dos defectos REALES encontrados y corregidos

**D-1 (bloqueante, silencioso): `checksums.txt` queda corrupto en la 2a corrida.**
`backup_local.ps1` hacia:

```powershell
$existing = Get-Content $checksumsFile | Where-Object { $_ -notmatch ... }
$existing + "$hash  $fileName" | Set-Content ...
```

Con **una sola** linea sobreviviente, `Get-Content` devuelve un **escalar** y
`+` **concatena strings** en vez de arrays: la linea nueva se pega a la anterior.
Resultado medido (R1, ver 3.1):

```
backup_2026-10-22_15-50-17.tar.gzEFD4406DC880A1D7068FC3501D1771CE9E...  backup_...
```

Consecuencias, medidas no supuestas:
- el `.tar.gz` se crea bien y el script sale **exit 0** (falla en silencio);
- `verify_backups.ps1` ya no puede parsear la linea (regex `^[A-Fa-f0-9]{64}\s+`)
  -> reporta **FALTANTE** un backup que existe;
- `restore_backup.ps1` no encuentra el registro -> cae al `[AVISO]` y **extrae sin
  verificar el checksum**, que es justo la garantia que el script promete.

Alcance: se dispara en la **segunda** corrida sobre cualquier destino nuevo (1
entrada previa que no matchea el nombre nuevo). No habia rastro en
`D:\Backups\juego-isla-ancestral` porque ese destino **no existe** todavia en esta
maquina: el bug es latente, no historico.
Fix: `@(...)` en la asignacion y `@($existing) + ...` al concatenar (+6 lineas).

**D-2: `& tar.exe` hereda el PATH.** Con un GNU tar delante (Git/MSYS, que es el
caso de esta maquina: `D:\WorkBuddyAI\resources\vendor\PortableGit\usr\bin\tar.exe`),
`-C 'C:\...'` se interpreta como `host:ruta` remota y el backup muere:

```
tar (child): cannot connect to c: resolve failed
tar.exe fallo con codigo 2
```

Reproducido en la primera corrida de la suite (rc=1, 0 backups). Fix: funcion
`Resolve-TarExe` que resuelve **explicitamente** `%SystemRoot%\System32\tar.exe`
(con fallback a `Get-Command`) y loguea la ruta elegida. Aplicada en
`backup_local.ps1` (compresion) y `restore_backup.ps1` (extraccion), que tenia el
mismo defecto.

## 4. Trampas nuevas (para el skill)

1. **PowerShell escalar vs array**: `Get-Content` devuelve escalar con UNA linea y
   `+` concatena strings. Un registro que "se ve bien" en la 1a corrida se
   corrompe en la 2a. En PowerShell, `@()` antes de cualquier `+` sobre resultados
   de pipeline.
2. **`tar.exe` por nombre no es portable**: GNU tar trata `C:\...` como host
   remoto. Resolver `%SystemRoot%\System32\tar.exe` explicitamente.
3. **El PATH del shell miente sobre el entorno real**: la suite corre con PATH de
   Task Scheduler (limpio) por defecto, y el PATH hostil se prueba aparte. Si se
   corre con el PATH heredado, se mide otra cosa y se culpa al script equivocado.
4. **Codepage OEM en PS 5.1**: decodificar el buffer ENTERO hace que una linea no
   UTF-8 arrastre todo a cp850 y una tilde quede partida. Decodificar linea por
   linea, y no poner acentos en las aserciones sobre mensajes de consola.
5. **Un `[?]` puede esconder trabajo verificable**: "no verificable headless" era
   cierto para el *hardware*, falso para la *logica* de verificacion.
