para medir exit codes de python en este entorno; usa invocacion nativa del

## P-17.6: gate anti-detector-ciego en generar_checklist_global.py

BUG-075 deja el gate de `generar_checklist_global.py` a cargo de atria-dawn
(DeepSeek cubrio solo `verificar_checklist.py`). Implementado y probado.

**Antes:** `leer_estructura_existente()` devolvia `(None, None, ...)` cuando
el global existia pero estaba **vacio o sin tabla**, y `generar_tabla()` caia
al default — reescribiendo el global y **perdiendo el prefijo/sufijo y el
esquema de columnas real** (lo que DeepSeek reparo en BUG-039). Detector
ciego puro.

**Ahora:** se levanta `DetectorCiegoError` (fail-fast) cuando el archivo
existe pero esta vacio o no contiene `| ID |`; `generar_tabla()` lo captura
y retorna **exit 3** con el mismo convenio que `verificar_checklist.py`.
El caso «archivo inexistente» sigue generando desde cero (primera
generacion legitima, exit 0).

Pruebas (con `--output <fixture>` y `--dry-run`):

| Caso | Exit |
|------|:----:|
| Vacio (0 bytes) | **3** |
| Sin tabla `\| ID \|` | **3** |
| Inexistente (1ra generacion) | **0** |
| CHECKLIST-GLOBAL real (control) | **0** — no se rompe el flujo normal |

Sin BOM, LF conservado.
