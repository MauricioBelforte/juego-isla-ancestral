## Resumen

Fix del **BUG-048** (critico, M53): la UI del juego no compilaba en runtime. Detectado como
hallazgo colateral durante el QA de M38 (Log 982). Alcance limitado a restaurar la compilacion —
no se avanza el checklist de M53.

## Causa raiz (dos problemas independientes)

1. **`scripts/ui/theme/theme_ux.gd:168`** — `for child in node.get_children(): if child is Tween:`.
   Godot 4.7 infiere el tipo estatico de `child` como `Node` y la comprobacion `child is Tween` da
   parse error (Tween es RefCounted, no Node). Cascada: theme_ux.gd no compilaba →
   theme_service.gd no resolvia la clase `ThemeUx` → `ThemeUx.new()` fallaba con "Nonexistent
   function 'new' in base 'GDScript'" → todo lo que tocaba el tema fallaba al cargar.
2. **`scripts/ui/layers/dialog_layer.gd:122` y `:269`** — `_on_node_entered` declarada DOS VECES
   (merge/rebase mal resuelto). La 122 era la version antigua (sin typing effect ni pausa de
   reloj); la 269 es la completa (M53 D).

## Solucion

- `theme_ux.gd`: iterar por indice con tipado `Variant` explicito
  (`var child: Variant = node.get_child(i)`).
- `dialog_layer.gd`: eliminada la version duplicada de la linea 122, con comentario explicativo;
  se conserva la completa (seccion "M53 D").

## Error nuevo para GUIA-GODOT/06-registro-errores.md

**Mensaje:** `Parse Error: Expression is of type "Node" so it can't be of type "Tween".`
**Causa:** iterar `for child in node.get_children()` da a `child` el tipo estatico `Node`;
comprobaciones `is` contra tipos no derivados de Node (Tween es RefCounted) son rechazadas por el
compilador.
**Solucion:** tipar la variable como `Variant` explicitamente (`var child: Variant =
node.get_child(i)`) o iterar por indice sin declaracion de tipo inferido.
**Fecha:** 2026-09-18 (atria-dawn, Log 983, archivo theme_ux.gd:168).
