## Cambios Realizados

### 1. BUG-061 (M94) — PRODUCCIÓN ROTA por JSON divergente
- **Diagnóstico:** `motivacion_manager.gd` y `objetivo_data.gd` (clase canónica) leen `plazo`,
  `cantidad_requerida`, `recompensa_id`, `recompensa_cantidad`. El JSON "v2" usaba `cadencia`
  ("diario_suave" ×7), `target_min` y `recompensa` como string con coma — campos que **no existen
  en ningún .gd**. Consecuencias: `objetivos_por_plazo()` devolvía [] en los tres plazos (fail
  size=0 ×3) y `cantidad_requerida` caía al fallback 1 → el primer `registrar_progreso` completaba
  de inmediato (2 fails de lógica de progreso). Código, clase canónica, suite y diseño
  (`03-Diseno.md` §3, `04-Codigo.md` §3: 3 diarios + 2 semanales + 2 mensuales) eran consistentes
  entre sí; el JSON era el artifact aislado (celebrado como "v2" en el ítem 209 del checklist del
  módulo — se escribió sin verificar contra el código).
- **Fix:** se reescribió `objetivos.json` con el esquema canónico y la distribución documentada
  (diarios: recolectar_madera=10, hablar_con_vecinos=8, regalar_regalo=1; semanales: pescar_tres=10,
  minerales=12; mensuales: construir_mueble=15, explorar_isla=20; recompensas parseadas de los
  strings a `recompensa_id`/`recompensa_cantidad`). **No se tocó código ni test.**
- **Verificación:** `Godot_v4.7.2 --headless --script res://scripts/motivacion/test_motivacion_m94.gd`
  → **EXIT 0 — 38 checks, 0 fallos** (antes 38/5, EXIT 1).
