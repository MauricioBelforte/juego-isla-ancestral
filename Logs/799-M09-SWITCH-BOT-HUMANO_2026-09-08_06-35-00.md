# Log 799: M09 — switch de modo bot/humano en el bot de paseo

**Fecha:** 2026-09-08
**Hora:** 06:35
**Modelo:** glm-5.3-flash
**Plataforma:** Kilo Code

## Resumen
El usuario reportó que el bot de paseo se ejecutaba automáticamente en cada arranque ("el problema es que me ejecutó el movimiento automático del personaje... ahora lo quería mover yo"). Implementado el **switch**: el bot SOLO corre si el juego se lanza con el flag `-- paseo`.

## Cómo usar
```
Modo bot (paseo automático + capturas):
  Godot.exe --path game/isla-ancestral -- paseo

Modo humano (vos movés el personaje):
  Godot.exe --path game/isla-ancestral   (normal)
```

## Cambios Realizados
- `scripts/world/bot_paseo_m09.gd`: en `_ready()` lee `OS.get_cmdline_user_args()` — solo se activa si encuentra `paseo`; si no, `set_process(false)` + log `[BOT] Desactivado (modo humano)`.

## Evidencia
- Boot normal: `[BOT] Desactivado (modo humano — lanza con `-- paseo` para activar el paseo automático)` — el bot no corrió, el jugador movió el personaje manualmente. 0 errores.
