## Cambios Realizados

1. **Lectura del código real:** `puzzle_room.gd`, `puzzle_emisor.gd`, `puzzle_puerta.gd`, `test_puzzles.gd`, `puzzle_invariant.gd` (M66).
2. **BUG DETECTADO (integración desconectada):** `PuzzleRoom.set_emisor/toggle_emisor` no recalculaban ni notificaban. El `PuzzleEmisor.recibir_golpe()` llamaba `sala.set_emisor(...)` pero la puerta nunca se enteraba → el framework emisor→receptor no abría puertas automáticamente en runtime (solo pasaba en tests unitarios aislados que llamaban `recalcular()` manualmente).
3. **Fix aplicado:**
   - `PuzzleRoom`: agregado `al_cambiar: Callable` + `_notificar()` que recalcula y dispara el callback en `set_emisor`/`toggle_emisor`.
   - `PuzzlePuerta`: agregado `nombre_receptor` + `evaluar(activos: Array)` que abre la puerta si su nombre está en la lista de receptores activos.
   - `test_puzzles.gd`: nuevo `_test_integracion_emisor_puerta()` verifica el ciclo completo (golpear emisores → puerta se abre vía callback).
4. **Hallazgo honesto:** `recalcular()` usa `completada=true` inicial y lo pone `false` si ALGUNA regla falla → para multi-puerta independiente "sala completada" solo es true si TODAS abren. Válido para el caso de una puerta objetivo; ambiguo para multi-receptor. No se cambió para no romper el test existente (nota para dueño).
