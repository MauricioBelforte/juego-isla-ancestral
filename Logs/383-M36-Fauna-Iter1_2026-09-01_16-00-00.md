## Decisiones clave

1. **Sin class_name en los scripts propios** (07-GUIA-GODOT §9.17): `fauna_species`, `fauna_catalog`, `fauna_registry`, `fauna_manager` se preloadean. `fauna_behavior` SÍ tiene class_name (es instanciable via `.new()` y un script por nodo). El test headless --script funciona via preload.

2. **Dedupe con `Time.get_unix_time_from_system()`**: `Time.get_ticks_msec()/1000.0` da tiempo desde arranque del motor (0 al inicio), no tiempo real. Descubierto en debugging: con ticks, el primer avistamiento ya tenía `ahora - ultimo = 1.09` que se interpretaba como < 30s → siempre return. Con unix time, el dedupe de 30s funciona entre sesiones reales.

3. **Catalog.json como fuente + fallback in-code**: el JSON tiene 7 especies cubriendo 6 biomas distintos. Si el JSON falla (test aislado, cambios de versión), el fallback in-code con 5 especies (playa/bosque_ancestral/pradera/ribera/bosque) sigue permitiendo que el modulo funcione.

4. **FSM delega movimiento via señal** (no dependencia a M65): `fauna_behavior` emite `solicitar_movimiento(destino, velocidad)`. Si M65 está implementado, lo consume y mueve el nodo. Si M65 no existe, el comportamiento no se mueve pero la FSM sigue validando transiciones de estado. Esto evita acoplamiento directo y permite que M36 funcione aunque M65 esté en otro estado.

5. **Dedupe en el test resetea con `keys_est = _dict.keys().duplicate()`**: en Godot 4, iterar sobre las keys de un dict mientras lo modificás con `erase` rompe el iterador. `duplicate()` soluciona.

## Pitfalls documentados (memoria colectiva)

- **`Time.get_ticks_msec()/1000` no es unix time**: arranca en 0 al abrir el juego, no sirve para medir "30s reales entre sesiones". Usar `Time.get_unix_time_from_system()` para dedupe/timestamps reales.
- **Iterar dict.keys() mientras modificas con .erase()**: rompe el iterador en Godot 4. Usar `.keys().duplicate()`.
- **`class_name` y `preload()` en `--script` headless**: los class_name NO se registran globalmente en este modo. Usar `const X = preload("res://path.gd")` y `X.EnumName.VALUE`.
- **No retornar tipos `FaunaSpecies` desde catalog**: si FaunaSpecies no tiene class_name, la firma `-> FaunaSpecies` falla. Usar `-> Resource` o `-> RefCounted` y documentar en comentarios.
- **Reescribir funciones con Edit puede duplicar el codigo**: el segundo Edit fallo al matchear exactamente y el contenido quedo duplicado (linea 88-92 tenia dos `## API publica` y dos `func obtener`). Leccion: despues de edits grandes, verificar el contenido.
