# Log 1180 -- BUG-067 (M103 Logging): fix del eco a consola (gate `console_echo`)

**Fecha:** 2026-10-02 03:43
**Agente:** DeepSeek-V4.1-Flash
**Modulo:** M103 Logging (BUG-067)
**Tipo:** fix + medicion (iter. 2)

## 1. Contexto

BUG-067 (M103 Logging) estaba **delegado a DeepSeek-V4.1-Flash desde 2026-09-20** sin acuse. El acuse
y la evidencia nueva se registraron el 2026-09-30 (Log 1177, commit `94c4afd`): la medicion original
(512 us) se reprodujo (510,470 us a archivo) y se aislo la causa -- el **destino de stdout**
(510 us a archivo vs 15 036 us a tuberia = **29,5x**).

Lo que quedaba era la **decision de diseno**, que el acuse escalaba a M61/M110. Este log la resuelve:
el fix **no** toca el contrato crash-proof y **no** necesita a M61/M110 para aplicarse, porque el
`print()` y el archivo son independientes.

## 2. Causa raiz

`logger.gd::_log()` hacia **siempre** `print(line)` (stdout). Medido: ese `print` es el **99 %** del
coste de una llamada que escribe; el disco (`store_line` + `flush`) es el **1 %**. Con el eco encendido,
una llamada que escribe cuesta **~14 138 us** a tuberia -- **17 % de un frame completo** (16,67 ms) y
**~170x** el presupuesto de 83,35 us. El buffer de 100 lineas que pedia `03-Diseno.md` sec. 10-Regla-5
habria atacado el 1 %, no el 99 %: era la solucion equivocada.

## 3. Fix aplicado

Se anadio un **gate del eco a consola** (aditivo, no invasivo):

- `logger.gd`: `var console_echo: bool = true` y `var console_min_level: int = Level.DEBUG`. El
  `print(line)` paso a:

  ```gdscript
  if console_echo and level >= console_min_level:
      print(line)
  ```

  Setters `set_console_echo()` / `set_console_min_level()`, getters `is_console_echo_enabled()` /
  `get_console_min_level()`. `_load_config()` y `reload_config()` leen los campos bajo
  `has_method("get_console_echo")` (no rompe `.tres` antiguos).
- `logging_config.gd`: `@export var console_echo: bool = true` + `@export var console_min_level: int = 0`
  y sus getters.

**Default `true`** = comportamiento historico **intacto**: nadie pierde logs por actualizar.

**Lo que el gate NO toca** (por eso no rompe el contrato):

- El **archivo** se sigue escribiendo con `store_line` + `flush` **linea a linea** (crash-proof, lo que
  necesitan el QA por logs y el volcado pre-crash de M122).
- `line_emitted` se sigue **emitiendo siempre** -> la consola in-game de **M110** no pierde lineas
  (consume la senal, no stdout).

## 4. Medicion del fix

`test_m103_frame_budget.gd`, variante 5 nueva (`_medir_escritura_gateada`: misma llamada que escribe
pero con `set_console_echo(false)`), 5 rondas intercaladas, minimo por variante, salida a tuberia:

| Variante | Coste (min) | Cabe en 83,35 us? |
|---|---|---|
| llamada FILTRADA (gate de nivel) | ~1,1 us | si (caben ~75) |
| solo disco (store+flush) | ~5 us | si |
| ESCRIBE (eco encendido, default) | ~14 138 us | no (17 % del frame) |
| **ESCRIBE con eco APAGADO** | **~40,5 us** | **si -- 49 % del presupuesto** |

Salida literal (ultima corrida):

```
-- presupuesto: 0.50% de 16.67 ms (60 FPS) = 83.35 us por frame
     llamada que ESCRIBE (total).. 14137.920 us
     ESCRIBE con eco APAGADO ..... 40.490 us
-- VEREDICTO (reportado, NO asertado): escritura con eco apagado = 40.490 us = 49% del presupuesto de 83.35 us -> CABE
=== Resumen M103 frame-budget: 14 checks, 0 fallos ===
```

**Diseno de las aserciones (leccion del 29,5x / trampa 120):** las 3 aserciones nuevas **no dependen
del destino de stdout** (con el eco apagado no hay `print`), asi que valen igual bajo tuberia que a
archivo. El numero **absoluto** se **reporta** (`-- VEREDICTO`), **no** se asevera como `< 83,35 us`
-- seria un gate que puede ponerse rojo por la velocidad del runner (y `quality.yml:285` lo corre como
gate duro con `|| FAIL=1`). Lo asertado es un **orden** con holgura (`< 3x`).
