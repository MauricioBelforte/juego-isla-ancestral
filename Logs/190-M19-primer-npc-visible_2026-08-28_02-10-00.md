## Errores Corregidos
1. **VillagerProfile type not found** — `class_name` no registraba el tipo. Solución: eliminado `class_name` y usar `preload()` + `Resource` como tipo
2. **VillagerMood type not found** — Mismo problema. Solución: `preload()` + `Node`
3. **Inventario/ItemDatabase not found** — MCP no carga autoloads. Solución: `get_node_or_null("/root/...")`
4. **Variant inference** — `:=` no funciona con `Node` dinámico. Solución: `var x = ...` sin tipo
5. **CanvasLayer show() override** — (corregido en M53 anterior)
