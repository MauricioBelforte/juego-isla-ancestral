### 3.3 Defecto medido: el wrapper descarta el exit code del hijo (falso verde)

`tests/test_m20_amistad_suites.gd::_ejecutar()` tiene 3 returns: `-1` si
`create_process` falla, `-1` si hay TIMEOUT, y el normal:

```gdscript
return {"rc": 0, "salida": salida}      # el exit del hijo NO se lee
```

`OS.create_process` devuelve un pid y `OS.is_process_running` un bool: Godot 4 no
expone el exit code del hijo, asi que la senal se pierde por diseno. El check
`int(r["rc"]) == 0` solo puede fallar por "no arranco" o "timeout", **nunca por un
suite que falla**.

**Prueba EN ROJO** (sonda temporal, borrada y verificada: `git status` de `tests/`
vacio): se reemplazo la 3a suite por una que imprime `=== Resumen: 5 checks, 0
fallos ===` y hace `quit(1)`:

```

=== Resumen: 8 checks, 0 fallos ===
TEST ... OK - M20 esta en el circuito central (72 checks verificados)
EXIT=0
```

Un suite que sale **1** pasa el wrapper como **rc=0 / TEST OK**. Es la trampa 85
(suite muerta que imprime "0 fallos") entrando al circuito central sin que nada
la vea.

## 7. Trampas nuevas para el skill

1. **Un wrapper de suites que redirige stdout pero no captura el exit code no
   puede fallar por el motivo que existe.** `OS.create_process` + redirect da la
   salida, no el codigo: hay que pedir `%ERRORLEVEL%` en la misma invocacion o usar
   `OS.execute` (que si devuelve el rc). Un check `rc == 0` sobre un valor que el
   codigo nunca setea distinto de 0 es una asercion muerta disfrazada de guard.
2. **Antes de aceptar "0 cerrables", hay que probar que la renumeracion BAJA el
   conteo.** Medir el efecto de la accion propuesta sobre la metrica, no solo si
   la accion es correcta: renumerar 5 ids habria costado 5 decisiones y el numero
   habria quedado en 18.
3. **Un bloque-puntero de consolidacion puede ser la UNICA copia de un metadato.**
   Al demotar un encabezado duplicado, sus campos (`Severidad`, `Estado`) quedan
   huerfanos lejos de la entrada canonica: el transcriptor los pierde y el reporte
   dice "la entrada no declara estado" cuando si lo declara, en otro lado. Medir
   la entrada Y su puntero.
