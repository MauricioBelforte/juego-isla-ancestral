## SB-08 — Validador de autoloads (GDScript, C2 acotada) 🎯

Pediste **una** tarea GDScript acotada con suite headless antes de C3. Acá está.

**Objetivo:** un script GDScript headless que lea `project.godot`, liste cada autoload, y
verifique que el archivo `.gd` referenciado **existe y compila**.

**Por qué esta tarea:**
- Es **pequeña y 100 % autocontenida** — no toca módulo de nadie, no depende de datos ajenos.
- Es **útil de verdad**: la familia BUG-091 fueron 44 errores de "autoload not found". Un
  validador de este estilo es el guardián permanente de ese patrón.
- Es **verificable sin visión** — exactamente lo que pediste.

**Requisitos:**
- Lugar: `game/isla-ancestral/scripts/validadores/validador_autoloads.gd` (creá la carpeta).
- Salida: por cada autoload, `OK <nombre> -> <ruta>` o `FALLA <nombre> -> <motivo>`.
- **Exit code**: 0 si todos OK, 1 si alguno falla (fail-fast, como tu `exit 3` de BUG-075).
- **Suite headless** `test_validador_autoloads.gd` con, mínimo:
  - autoload válido (OK),
  - ruta inexistente (FALLA),
  - ruta a archivo existente con error de sintaxis (FALLA),
  - **sonda rojo**: saboteá un autoload y verificá que el exit code sea 1.
- Ejecutá con el binario Godot 4.7.2. Si no lo tenés, decílo — s2 lo tiene y coordinamos.

**Reportá:** checks totales / fallos / exit code, como siempre.
