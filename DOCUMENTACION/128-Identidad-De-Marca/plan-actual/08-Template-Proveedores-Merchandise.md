**Plataforma:** Kilo Code

**Encargo:** mimo-v2.6 (Director) — msg 48 del canal Ling-3.1-Flash (lote documental M128)
**Ítem del checklist:** G.L129 "Crear template para proveedores de merchandise"

> Spec sheet estándar que se entrega a todo proveedor de merchandise (POD, textil,
> cerámica, papel). Completa las reglas de M128 §9 (Merchandise) y §2 (logo) con los
> datos técnicos de impresión de §3 (paleta CMYK).

## Template (spec sheet por proveedor)

### 1. Datos del proveedor

| Campo | Valor |
|-------|-------|
| Nombre / región | __________ |
| Contacto | __________ |
| Productos que ofrece | textil / cerámica / papel (estándares de calidad M128 §G) |
| Aprobación como proveedor | pendiente — proceso de M128 §9 "Aprobación" + criterios de selección (03-Diseno §1.7) |

### 2. Productos permitidos (M128 §9 — usos permitidos)

- Solo los productos de la lista aprobada de M128 §9 (qué productos de merchandise se
  permiten — ya definida `[x]` en el checklist).
- Fuera de la lista: requiere aprobación explícita del contacto de marca (M128 §10 del
  manual).

### 3. Especificaciones de impresión

| Elemento | Especificación |
|----------|----------------|
| Logo mínimo (impresión) | 10 mm de altura (M128 §2 "Tamaño Mínimo") |
| Espacio libre (clear space) | altura del logo / 4 en todas las direcciones (M128 §2) |
| Color de impresión | CMYK de la paleta oficial (M128 §3): Azul Bosque 78, 30, 58, 24 · Dorado Anciano 10, 30, 80, 5 · Blanco Perla 3, 4, 8, 0 |
| Guía CMYK vs RGB | M128 §G (ya definida `[x]`) — no convertir colores por ojo; usar la tabla |
| Tipografía en producto | Display (Fredoka One) para títulos; Texto (Nunito) para cuerpo (M88) |

### 4. Restricciones de calidad (M128 §9)

- No distorsionar, no estirar, no recolorear, no rotar el logo (usos PROHIBIDOS, M128 §2).
- No añadir efectos (sombra, brillo, 3D) sobre el logo.
- Muestreo antes de producción (M128 §G — proceso de muestreo ya definido `[x]`).
- Restricciones de calidad por material (textil, cerámica, papel) según M128 §G.

### 5. Proceso de aprobación de diseños (M128 §G)

1. Proveedor envía mockup del diseño.
2. Validación contra este template (logo, clear space, CMYK, tipografía).
3. Aprobación por el contacto de marca (M128 §10: quién puede aprobar cambios de marca).
4. Muestra física antes de producción en serie.

### 6. Recepción de producto

> ⚠️ **Pendiente (drift L136 `[?]`):** el "checklist de QA para merchandise recibido" es
> uno de los 4 ítems `[?]` del módulo (auditoría BUG-070 lote 7: la cita
> "03-Diseno.md §9 QA checklist" no existe — §9 solo tiene Usos/Restricciones/
> Aprobación). Este template **no** incluye checklist de recepción hasta que el dueño
> del drift lo resuelva. No fabricar contenido para ese ítem.

## Uso del template

- Copiar la spec sheet por proveedor; completar la sección 1 y adjuntar las secciones
  2-5 como anexo técnico.
- Archivar la spec sheet firmada junto al diseño aprobado (trazabilidad M128 §9).
