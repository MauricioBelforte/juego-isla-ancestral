Seguimos con **una rutina completa de NPC**, usando los componentes que ya tenemos:

```text
Esperar navegación
→ pedir entrada a la casa
→ esperar turno y cruzar
→ elegir una silla disponible
→ acercarse y sentarse
→ permanecer sentado
→ levantarse
→ pedir salida
→ cruzar hacia fuera
→ terminar o repetir
```

Esta vez reemplazamos los scripts de prueba por **un coordinador de rutina**.

**Decisión importante:** si falla un cruce a mitad de camino, no suponemos que el NPC sigue fuera o dentro. La rutina se detiene para revisión. Reintentar desde un lado incorrecto podría enviarlo a través de la puerta sin respetar el turno.

> No he ejecutado esta integración en Godot. Está escrita para los componentes anteriores y necesita las pruebas del final.

---

# 1. Alcance de esta rutina

Esta primera versión trabaja con:

- Un NPC.
- Una casa asignada.
- Una puerta asignada.
- Las sillas cargadas por `InteriorCasa`.
- Reintentos limitados.
- Un tiempo configurable de uso.

Varios NPCs pueden tener este mismo componente y compartir:

```text
Casa
InteriorCasa
GestorPasoPuerta
```

Cada NPC conserva sus propios:

```text
ActorAsiento
AccionMueble
CrucePuerta
RutinaCasa
```

**No añadimos todavía selección entre distintas casas ni horarios diarios.** Primero cerramos correctamente una visita completa.

---

# 2. Reserva del mueble

La rutina no reserva una silla mientras espera fuera.

Hace esto:

```text
Entrar
→ buscar una silla disponible
→ solicitar su acción
```

`AccionMueble` reserva la silla al aceptar la solicitud.

Si no encuentra ninguna:

1. Espera unos segundos.
2. Vuelve a buscar.
3. Después de varios intentos, sale de la casa.

Así evitamos que un NPC bloquee una silla durante toda una espera en la puerta.

---

# 3. Suspender el comportamiento habitual durante toda la visita

Hasta ahora los componentes restauraban el controlador al terminar cada operación. Eso podría provocar:

```text
Termina el cruce
→ vuelve la deambulación
→ la rutina intenta elegir una silla
```

Lo resolveremos con un **bloqueo exterior**:

- `RutinaCasa` guarda los callbacks originales del controlador.
- Los desactiva durante toda la visita.
- Los componentes internos encuentran ese controlador ya suspendido.
- Al terminar sus acciones lo restauran al estado suspendido.
- Solo `RutinaCasa` devuelve finalmente el estado original.

Esto funciona con el mecanismo de callbacks que ya estamos usando.

**Sigue sin detener temporizadores, corutinas u otros nodos que muevan al actor por su cuenta.** Esos sistemas deben respetar el control externo.

---

# 4. Añadir el componente

Estructura:

```text
NPC
├── CollisionShape3D
├── Modelo
├── ActorAsiento
├── AgenteMuebles
├── AccionMueble
├── CrucePuerta
└── RutinaCasa
```

Guardá:

```text
res://casas/scripts/rutina_casa.gd
```

```gdscript
class_name RutinaCasa
extends Node

signal visita_terminada
signal rutina_detenida(motivo: String)

enum Estado {
	INACTIVA,
	ESPERANDO_NAV,
	ENTRANDO,
	BUSCANDO_SILLA,
	YENDO_A_SILLA,
	SENTADO,
	LEVANTANDO,
	SALIENDO,
	PAUSA,
	TERMINADA,
	DETENIDA,
}

@export_category("Referencias")
@export var cruce: CrucePuerta
@export var interior: InteriorCasa
@export var navegacion: NavegacionCasa

@export_category("Inicio")
@export var iniciar_automaticamente: bool = true

# La posición inicial debe estar realmente fuera de la casa.
@export var repetir_visita: bool = false
@export var pausa_entre_visitas: float = 15.0

@export_category("Uso")
@export var segundos_sentado: float = 8.0

@export_category("Reintentos")
@export var intervalo_reintento: float = 3.0
@export var intentos_maximos: int = 4
@export var tiempo_maximo_navegacion: float = 30.0

@export_category("Espera física")
@export var gravedad: float = 9.8

var estado: Estado = Estado.INACTIVA

var _accion: AccionMueble
var _asiento: ActorAsiento
var _actor: CharacterBody3D
var _control: Node

var _callbacks: Dictionary = {}
var _control_retenido: bool = false

var _espera: float = 0.0
var _tiempo_nav: float = 0.0

var _intentos: int = 0
var _silla_elegida: SillaCasa
var _conectada: bool = false


func _ready() -> void:
	if not _preparar_referencias():
		push_error("RutinaCasa: faltan referencias válidas.")
		return

	cruce.cruce_completado.connect(_al_cruzar)
	cruce.cruce_cancelado.connect(_al_fallar_cruce)

	_accion.accion_cancelada.connect(_al_fallar_mueble)
	_asiento.sentado.connect(_al_sentarse)
	_asiento.levantado.connect(_al_levantarse)

	_conectada = true

	if iniciar_automaticamente:
		call_deferred("iniciar")


func _preparar_referencias() -> bool:
	if (
		not is_instance_valid(cruce)
		or not is_instance_valid(interior)
		or not is_instance_valid(navegacion)
		or not is_instance_valid(cruce.accion)
	):
		return false

	_accion = cruce.accion
	_asiento = _accion.asiento
	_actor = _accion.actor

	if not is_instance_valid(_asiento) or not is_instance_valid(_actor):
		return false

	_control = (
		_asiento.controlador
		if _asiento.controlador != null
		else _actor
	)

	return (
		is_instance_valid(_control)
		and _control != self
		and _control != cruce
		and _control != _accion
		and _control != _asiento
	)


func iniciar() -> bool:
	if not _conectada:
		return false

	if estado not in [Estado.INACTIVA, Estado.TERMINADA]:
		return false

	if not _componentes_libres():
		return false

	_retener_controlador()

	_actor.velocity = Vector3.ZERO
	_tiempo_nav = 0.0
	_espera = 0.0
	estado = Estado.ESPERANDO_NAV
	return true


func _componentes_libres() -> bool:
	return (
		cruce.estado == CrucePuerta.Estado.LIBRE
		and _accion.esta_libre()
		and _asiento.esta_libre()
	)


func _physics_process(delta: float) -> void:
	if estado in [
		Estado.INACTIVA,
		Estado.TERMINADA,
	]:
		return

	if not _referencias_siguen_validas():
		_detener("Se perdió una referencia de la rutina.")
		return

	# Mientras ningún componente mueve al actor, mantener gravedad.
	# No se ejecuta durante cruce, aproximación o postura sentada.
	if _control_retenido and _componentes_libres():
		_mantener_en_suelo(delta)

	if estado == Estado.DETENIDA:
		return

	if estado == Estado.ESPERANDO_NAV:
		_tiempo_nav += delta

		if navegacion.preparada:
			_preparar_etapa(Estado.ENTRANDO)
		elif _tiempo_nav > tiempo_maximo_navegacion:
			_detener("La navegación no estuvo lista a tiempo.")

		return

	_espera = maxf(0.0, _espera - delta)

	match estado:
		Estado.ENTRANDO:
			if (
				_espera <= 0.0
				and cruce.estado == CrucePuerta.Estado.LIBRE
			):
				_intentar_cruce(true)

		Estado.BUSCANDO_SILLA:
			if _espera <= 0.0:
				_buscar_y_solicitar_silla()

		Estado.SENTADO:
			if _espera <= 0.0:
				_preparar_etapa(Estado.LEVANTANDO)

		Estado.LEVANTANDO:
			if (
				_espera <= 0.0
				and _asiento.estado == ActorAsiento.Estado.SENTADO
			):
				_intentar_levantarse()

		Estado.SALIENDO:
			if (
				_espera <= 0.0
				and cruce.estado == CrucePuerta.Estado.LIBRE
			):
				_intentar_cruce(false)

		Estado.PAUSA:
			if _espera <= 0.0:
				_preparar_etapa(Estado.ENTRANDO)


func _referencias_siguen_validas() -> bool:
	return (
		is_instance_valid(cruce)
		and is_instance_valid(interior)
		and is_instance_valid(navegacion)
		and is_instance_valid(_accion)
		and is_instance_valid(_asiento)
		and is_instance_valid(_actor)
	)


func _preparar_etapa(nueva: Estado) -> void:
	estado = nueva
	_intentos = 0
	_espera = 0.0


func _intentar_cruce(entrar: bool) -> void:
	if _intentos >= maxi(1, intentos_maximos):
		_detener(
			"No se pudo iniciar la entrada."
			if entrar
			else "No se pudo iniciar la salida."
		)
		return

	_intentos += 1
	_espera = maxf(0.2, intervalo_reintento)

	# No pasamos una silla: la elegimos después de entrar.
	cruce.solicitar_cruce(entrar)


func _al_cruzar() -> void:
	match estado:
		Estado.ENTRANDO:
			_preparar_etapa(Estado.BUSCANDO_SILLA)

		Estado.SALIENDO:
			_silla_elegida = null

			if repetir_visita:
				estado = Estado.PAUSA
				_espera = maxf(0.2, pausa_entre_visitas)
			else:
				estado = Estado.TERMINADA
				_devolver_controlador()

			visita_terminada.emit()


func _al_fallar_cruce(motivo: String) -> void:
	if estado not in [Estado.ENTRANDO, Estado.SALIENDO]:
		return

	# Puede haberse detenido antes, dentro o después del vano.
	# No intentamos deducir el lado a partir del estado anterior.
	_detener("Cruce interrumpido: " + motivo)


func _buscar_y_solicitar_silla() -> void:
	if _intentos >= maxi(1, intentos_maximos):
		print("RutinaCasa: no se consiguió silla; se solicita salida.")
		_preparar_etapa(Estado.SALIENDO)
		return

	_intentos += 1
	_espera = maxf(0.2, intervalo_reintento)

	var mejor: SillaCasa
	var distancia_mejor := INF

	for valor in interior.puntos.values():
		var silla := valor as SillaCasa

		if not is_instance_valid(silla):
			continue

		if (
			not silla.posicion_uso_definida
			or not silla.pose_definida
			or not silla.salida_definida
			or not silla.esta_disponible_para(_actor)
		):
			continue

		var distancia := _actor.global_position.distance_squared_to(
			silla.obtener_posicion_uso()
		)

		if distancia < distancia_mejor:
			mejor = silla
			distancia_mejor = distancia

	if mejor == null:
		return

	_silla_elegida = mejor

	# Cambiar estado antes de llamar: algunos rechazos emiten
	# accion_cancelada dentro de la misma solicitud.
	estado = Estado.YENDO_A_SILLA

	var aceptada := mejor.intentar_usar(_actor)

	if not aceptada and estado == Estado.YENDO_A_SILLA:
		estado = Estado.BUSCANDO_SILLA
		_silla_elegida = null


func _al_fallar_mueble(motivo: String) -> void:
	if estado != Estado.YENDO_A_SILLA:
		return

	print("RutinaCasa: aproximación fallida: ", motivo)

	_silla_elegida = null
	estado = Estado.BUSCANDO_SILLA
	_espera = maxf(0.2, intervalo_reintento)


func _al_sentarse() -> void:
	if estado != Estado.YENDO_A_SILLA:
		return

	estado = Estado.SENTADO
	_espera = maxf(0.1, segundos_sentado)


func _intentar_levantarse() -> void:
	if _intentos >= maxi(1, intentos_maximos):
		_detener(
			"La salida de la silla sigue bloqueada. "
			+ "El NPC conserva su asiento y su reserva."
		)
		return

	_intentos += 1
	_espera = maxf(0.2, intervalo_reintento)

	_asiento.pedir_levantarse()


func _al_levantarse() -> void:
	if estado not in [Estado.SENTADO, Estado.LEVANTANDO]:
		return

	_silla_elegida = null
	_preparar_etapa(Estado.SALIENDO)


func _detener(motivo: String) -> void:
	if estado == Estado.DETENIDA:
		return

	estado = Estado.DETENIDA

	# No devolver el controlador automáticamente:
	# el actor podría estar sentado o dentro de la puerta.
	push_warning("RutinaCasa detenida: " + motivo)
	rutina_detenida.emit(motivo)


func reintentar_salida_del_asiento() -> bool:
	if (
		estado != Estado.DETENIDA
		or not is_instance_valid(_asiento)
		or _asiento.estado != ActorAsiento.Estado.SENTADO
	):
		return false

	_preparar_etapa(Estado.LEVANTANDO)
	return true


func reanudar_desde_posicion(confirmar_dentro: bool) -> bool:
	# Usar solo después de revisar dónde quedó el personaje.
	if estado != Estado.DETENIDA:
		return false

	if not _referencias_siguen_validas() or not _componentes_libres():
		return false

	_preparar_etapa(
		Estado.BUSCANDO_SILLA
		if confirmar_dentro
		else Estado.ENTRANDO
	)
	return true


func devolver_control_tras_revision() -> bool:
	if estado != Estado.DETENIDA:
		return false

	if not _referencias_siguen_validas() or not _componentes_libres():
		return false

	estado = Estado.TERMINADA
	_devolver_controlador()
	return true


func _mantener_en_suelo(delta: float) -> void:
	_actor.velocity.x = 0.0
	_actor.velocity.z = 0.0

	if _actor.is_on_floor():
		_actor.velocity.y = 0.0
	else:
		_actor.velocity.y -= gravedad * delta

	_actor.move_and_slide()


func _retener_controlador() -> void:
	if _control_retenido:
		return

	_callbacks = {
		"process": _control.is_processing(),
		"physics": _control.is_physics_processing(),
		"input": _control.is_processing_input(),
		"unhandled": _control.is_processing_unhandled_input(),
		"key": _control.is_processing_unhandled_key_input(),
	}

	_control.set_process(false)
	_control.set_physics_process(false)
	_control.set_process_input(false)
	_control.set_process_unhandled_input(false)
	_control.set_process_unhandled_key_input(false)

	_control_retenido = true


func _devolver_controlador() -> void:
	if not _control_retenido:
		return

	if is_instance_valid(_control):
		_control.set_process(_callbacks.get("process", false))
		_control.set_physics_process(_callbacks.get("physics", false))
		_control.set_process_input(_callbacks.get("input", false))
		_control.set_process_unhandled_input(
			_callbacks.get("unhandled", false)
		)
		_control.set_process_unhandled_key_input(
			_callbacks.get("key", false)
		)

	_control_retenido = false
```

# 5. Evitar que siempre elija una silla inaccesible

El código anterior elige la silla disponible más cercana por distancia directa. Eso es sencillo, pero puede insistir en una silla cuyo punto de aproximación no tiene ruta.

Añadimos una pequeña lista de exclusión **para la visita actual**.

En `RutinaCasa`, añadí:

```gdscript
var _sillas_fallidas: Array[int] = []
```

En `_al_cruzar()`, dentro del caso `Estado.ENTRANDO`, antes de cambiar de etapa:

```gdscript
_sillas_fallidas.clear()
```

En el bucle de selección de sillas, después de comprobar que la referencia es válida:

```gdscript
if _sillas_fallidas.has(silla.get_instance_id()):
	continue
```

En `_al_fallar_mueble()`, antes de limpiar `_silla_elegida`:

```gdscript
if is_instance_valid(_silla_elegida):
	_sillas_fallidas.append(_silla_elegida.get_instance_id())
```

Y en el rechazo sin señal de `_buscar_y_solicitar_silla()`:

```gdscript
if not aceptada and estado == Estado.YENDO_A_SILLA:
	if is_instance_valid(_silla_elegida):
		_sillas_fallidas.append(_silla_elegida.get_instance_id())

	estado = Estado.BUSCANDO_SILLA
	_silla_elegida = null
```

Así, una aproximación fallida no monopoliza los siguientes intentos.

**Esto no certifica que la silla sea defectuosa:** pudo fallar por un obstáculo temporal. La exclusión se borra al comenzar otra visita.

# 7. Desactivar la tecla de levantarse en NPCs

Hasta ahora `ActorAsiento` escuchaba la acción `levantarse` para cualquier actor que lo tuviera.

Eso podría hacer que al pulsar H se levantaran varios NPCs a la vez.

En `actor_asiento.gd`, añadí:

```gdscript
@export var permitir_entrada_jugador: bool = true
```

Al comienzo de `_unhandled_input()`:

```gdscript
if not permitir_entrada_jugador:
	return
```

Configurá:

```text
Jugador:
    Permitir entrada jugador = true

NPCs:
    Permitir entrada jugador = false
```

El NPC seguirá levantándose mediante:

```gdscript
_asiento.pedir_levantarse()
```

# 8. Qué ocurre cuando algo falla

## No hay lugar en la cola

`CrucePuerta.solicitar_cruce()` rechaza la solicitud.

La rutina espera y reintenta, hasta el límite configurado.

## Todas las sillas están ocupadas

La rutina busca varias veces. Si no consigue ninguna, solicita salir.

## La aproximación a una silla falla

Se libera la reserva mediante `AccionMueble`, se excluye esa silla durante la visita y se prueba otra.

## La salida del asiento está bloqueada

El NPC:

- Sigue sentado.
- Conserva la reserva.
- Reintenta levantarse.
- Si agota los intentos, queda en `DETENIDA`.

Después de retirar el obstáculo:

```gdscript
rutina.reintentar_salida_del_asiento()
```

## Un cruce se interrumpe

La rutina queda en `DETENIDA`.

Después de revisar y, si hace falta, apartar al personaje del vano:

```gdscript
# El NPC está realmente dentro:
rutina.reanudar_desde_posicion(true)

# El NPC está realmente fuera:
rutina.reanudar_desde_posicion(false)
```

**Estos métodos no teletransportan ni verifican automáticamente el lado.** La confirmación la da quien llama.

# 9. Prueba recomendada

### Prueba A — Una visita normal

Con una silla libre:

```text
NPC fuera
→ espera turno
→ entra
→ elige silla
→ se sienta
→ espera 8 segundos
→ se levanta
→ sale
→ recupera su comportamiento
```

### Prueba B — Sin sillas disponibles

Reservá u ocupá todas las sillas.

El NPC debe entrar, esperar sus intentos y salir sin sentarse.

### Prueba C — Dos NPCs

Ambos usan:

- La misma casa.
- El mismo gestor de puerta.
- Distintos componentes personales.

Comprobá que no reservan la misma silla simultáneamente.

### Prueba D — Salida del asiento bloqueada

Colocá un obstáculo en el punto de salida.

El NPC debe permanecer sentado, no aparecer de pie atravesando el obstáculo.

### Prueba E — Repetición

Solo después de aprobar las anteriores:

```text
Repetir visita = true
Pausa entre visitas = 15 s
```

Durante esa pausa, el controlador habitual permanece suspendido. El NPC espera cerca del destino exterior del cruce.

**Ese punto debe quedar fuera del pasillo y del barrido.** Si querés que espere en una plaza o en su casa, la próxima ampliación debe añadir un destino exterior de descanso, no devolverle deambulación sin coordinarla.

---

## Precaución de ciclo de vida

No retires `RutinaCasa` ni descargues la casa mientras la visita está activa. Los componentes mantienen reservas y estados de control.

Esta entrega todavía no implementa una cancelación global segura durante:

- La alineación sentada.
- Una salida bloqueada.
- Un cruce dentro del vano.

Para terminar manualmente una rutina detenida, con el actor de pie y los componentes libres:

```gdscript
rutina.devolver_control_tras_revision()
```

---

## Resultado

Ya tenemos una **visita autónoma completa**, no solo órdenes aisladas:

```text
Entrada coordinada
→ elección de mueble
→ reserva y aproximación
→ uso temporizado
→ salida comprobada
→ salida de la casa
→ restauración del comportamiento
```

El siguiente avance útil es **sacar los tiempos, destinos y preferencias del código y convertirlos en perfiles de rutina**: por ejemplo, un vecino que desayuna, otro que lee y otro que visita una casa por la tarde, sin duplicar la lógica de circulación.
