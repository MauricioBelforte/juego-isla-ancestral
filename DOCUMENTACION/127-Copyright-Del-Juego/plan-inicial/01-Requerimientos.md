# 01-Requerimientos.md — Módulo 127: Copyright del Juego

## ID del Módulo
- **Código:** M127 (plan maestro: sección 126 — Copyright del Juego)
- **Carpeta:** `DOCUMENTACION/127-Copyright-Del-Juego/`
- **Dependencias:** M78 (Legal General), M128 (Identidad de Marca), M41 (Música)
- **Carácter:** Módulo de copyright del juego

## 1. Problema

El proyecto necesita registrar copyright del juego. Debe registrar obras relevantes cuando corresponda, registrar código, registrar arte, registrar música, registrar narrativa, registrar logos y mantener evidencia de autoría.

## 2. Requisitos Funcionales

| # | Requisito | Detalle |
|---|---|---|
| RF1 | Registrar obras relevantes | Registrar obras relevantes cuando corresponda (código, arte, música, narrativa, logos) |
| RF2 | Registrar código | Registrar código fuente del juego (Copyright automatico en creación) |
| RF3 | Registrar arte | Registrar arte del juego (assets 2D/3D, texturas, sprites) |
| RF4 | Registrar música | Registrar música del juego (tracks, efectos de sonido) |
| RF5 | Registrar narrativa | Registrar narrativa del juego (historia, diálogos, NPC) |
| RF6 | Registrar logos | Registrar logos del juego (logos, branding) |
| RF7 | Mantener evidencia de autoría | Mantener evidencia de autoría (git logs, timestamps, borradores) |

## 3. Requisitos No Funcionales

- Copyright es automatico en creación (no requiere registro formal en muchos países)
- Registro formal (USCO, etc.) es opcional pero recomendado para protección legal
- Evidencia de autoría es critica para disputas de copyright
- Mantener registros de git logs, timestamps, borradores

## 4. Criterios de Aceptación

1. Los 7 puntos de la sección 126 del plan maestro resueltos.
2. Registro de código (copyright automatico, git logs).
3. Registro de arte (copyright automatico, timestamps).
4. Registro de música (copyright automatico, timestamps).
5. Registro de narrativa (copyright automatico, timestamps).
6. Registro de logos (copyright automatico, timestamps).
7. Evidencia de autoría mantenida (git logs, timestamps, borradores).
