# 01-Requerimientos.md — Módulo 125: Términos de Servicio

## ID del Módulo
- **Código:** M125 (plan maestro: sección 124 — Términos de Servicio)
- **Carpeta:** `DOCUMENTACION/125-Terminos-De-Servicio/`
- **Dependencias:** M78 (Legal General), M106 (Seguridad), M60 (Datos y Serialización)
- **Carácter:** Módulo de términos de servicio para el juego

## 1. Problema

El proyecto necesita unos **términos de servicio** legales para el juego. Debe redactar términos, definir licencia de uso, definir cuentas, definir conductas prohibidas, definir contenido de usuarios, definir cancelaciones, definir reembolsos, definir responsabilidad, definir cambios del servicio, definir terminación, definir jurisdicción aplicable y revisar con abogado.

## 2. Requisitos Funcionales

| # | Requisito | Detalle |
|---|---|---|
| RF1 | Redactar términos | Redactar términos de servicio legales del juego |
| RF2 | Definir licencia de uso | Definir licencia de uso del juego (personal, no comercial) |
| RF3 | Definir cuentas | Definir términos para cuentas de usuario (si aplica) |
| RF4 | Definir conductas prohibidas | Definir conductas prohibidas (cheating, explotación, acoso) |
| RF5 | Definir contenido de usuarios | Definir términos para contenido generado por usuarios (si aplica) |
| RF6 | Definir cancelaciones | Definir política de cancelación de cuentas (si aplica) |
| RF7 | Definir reembolsos | Definir política de reembolsos (según política de Steam) |
| RF8 | Definir responsabilidad | Definir limitación de responsabilidad del desarrollador |
| RF9 | Definir cambios del servicio | Definir cambios del servicio y actualizaciones |
| RF10 | Definir terminación | Definir terminación de cuentas y acceso al servicio |
| RF11 | Definir jurisdicción aplicable | Definir jurisdicción aplicable (leyes locales) |
| RF12 | Revisar con abogado | Revisar términos de servicio con abogado |

## 3. Requisitos No Funcionales

- Términos deben ser claros y comprensibles para el usuario promedio
- Términos deben cumplir con leyes locales (GDPR, CCPA, etc.)
- Términos deben ser coherentes con filosofía cozy del juego
- Términos deben ser justos y no predatorios
- Términos deben estar disponibles en el juego y en el sitio web

## 4. Criterios de Aceptación

1. Los 12 puntos de la sección 124 del plan maestro resueltos.
2. Términos de servicio redactados (claros y comprensibles).
3. Licencia de uso definida (personal, no comercial).
4. Cuentas de usuario definidas (si aplica).
5. Conductas prohibidas definidas (cheating, explotación, acoso).
6. Contenido de usuarios definido (si aplica).
7. Política de cancelación definida (si aplica).
8. Política de reembolsos definida (según política de Steam).
9. Limitación de responsabilidad definida.
10. Cambios del servicio definidos.
11. Terminación de cuentas definida.
12. Jurisdicción aplicable definida.
13. Términos revisados por abogado.
